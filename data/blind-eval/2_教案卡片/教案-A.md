# 教案 A

> 请仅依据教案内容作答，不要猜测作者或来源。

| 项目 | 内容 |
|---|---|
| 主题 | 生活自理课《穿鞋子》 |
| 适用年龄 | 3-9岁 |
| 单次时长 | 约 30 分钟 |
| 活动领域 | 生活自理 |

## 一、活动总目标（有益经验）

1. 能说出鞋子的基本组成部分。
2. 能正确区分左右鞋。
3. 能独立完成穿鞋子的过程。

## 二、分层活动目标

| 层级 | 支持方式 | 活动目标 | 达成标准 |
|---|---|---|---|
| A | 示范模仿 | 能在老师示范后跟随做 2 个穿鞋动作 | 全班幼儿中至少 4 名能达到 |
|  | 大量身体辅助 | 能在老师的大量身体辅助下尝试穿鞋 | 全班幼儿中至少 2 名能达到 |
|  | 示范模仿 | 能在老师示范后模仿穿鞋的动作 | 全班幼儿中至少 4 名能达到 |
| B | 手势辅助 | 能在老师的手势辅助下完成 3 个穿鞋动作 | 全班幼儿中至少 3 名能达到 |
|  | 少量身体辅助 | 能在老师的少量身体辅助下完成穿鞋 | 全班幼儿中至少 3 名能达到 |
|  | 手势辅助 | 能在老师的手势提示下完成穿鞋 | 全班幼儿中至少 3 名能达到 |
| C | 独立完成 | 能独立完成 5 个穿鞋动作 | 全班幼儿中至少 5 名能达到 |
|  | 独立完成 | 能独立穿好鞋子并检查是否穿对 | 全班幼儿中至少 5 名能达到 |

## 三、材料准备

- 彩色鞋盒模型 3套
- 不同颜色和款式的鞋子 12双
- 鞋子图片 24张
- 操作图卡 12张
- 小镜子 3面
- 计时器 1个

## 四、环境与安全

- **环境**：活动室地面清洁，环境安静，有足够空间进行活动。
- **安全**：活动材料均为大尺寸、无尖角，使用前检查有无破损；精细动作环节需教师全程在旁，避免幼儿将小件材料放入口中。

## 五、教学过程

### （一）师生互动

**时长**：4 分钟

**师生问好**
- 教师语言：师：摇铃鼓，小朋友们请坐好，今天我们要学习穿鞋子，准备好了吗？
- 幼儿表现：幼儿坐好，跟随音乐节奏拍手，回应‘准备好了’。
- 视觉/手势提示：教师摇铃鼓，展示笑脸。
- 支持措施：教师走到需要较多支持的幼儿旁边，轻轻拍拍他们的肩膀，给予鼓励。
- 观察要点：观察幼儿是否能坐好，是否跟随音乐节奏拍手。

**点名互动**
- 教师语言：师：现在我们来点名，谁的名字是‘小苹果’，请举手。
- 幼儿表现：被点到名的幼儿举手。
- 视觉/手势提示：教师用手指指向被点名的幼儿。
- 支持措施：教师用手指引导需要较多支持的幼儿举手。
- 观察要点：观察幼儿是否能正确回应自己的名字。

### （二）热身活动

**时长**：3 分钟

**热身律动**
- 教师语言：师：现在让我们来做做律动，跟着老师的节奏动起来。
- 幼儿表现：幼儿跟随音乐节奏做简单的拍手、跺脚动作。
- 视觉/手势提示：教师展示拍手、跺脚的动作。
- 支持措施：教师站在需要较多支持的幼儿旁边，轻轻触碰他们的手或脚，引导他们做动作。
- 观察要点：观察幼儿是否能跟随节奏做动作。

### （三）主题课活动

**时长**：16 分钟

**活动导入**
- 教师语言：师：看，老师这里有一些鞋子，我们一起来看看它们是什么样子的。
- 幼儿表现：幼儿观察老师手中的鞋子。
- 视觉/手势提示：教师展示不同颜色和款式的鞋子。
- 支持措施：教师将鞋子放在需要较多支持的幼儿视线水平高度。
- 观察要点：观察幼儿是否能集中注意力观察鞋子。

**核心活动**
- 教师语言：师：现在我们要学习穿鞋子，先看老师怎么示范。
- 幼儿表现：幼儿观察老师穿鞋子的动作。
- 视觉/手势提示：教师展示穿鞋子的步骤。
- 支持措施：教师手把手地教需要较多支持的幼儿穿鞋，逐步减少辅助。
- 观察要点：观察幼儿是否能跟随老师的示范做穿鞋动作。

### （四）活动结束

**时长**：7 分钟

**复练与小结**
- 教师语言：师：现在请小朋友们尝试自己穿鞋子，可以按照老师刚才教的方法。
- 幼儿表现：幼儿尝试自己穿鞋子。
- 视觉/手势提示：教师展示正确的穿鞋动作。
- 支持措施：教师站在需要较多支持的幼儿旁边，给予口头提示和身体辅助。
- 观察要点：观察幼儿是否能独立完成穿鞋动作。

**结束与延伸**
- 教师语言：师：今天我们学习了穿鞋子，回家后请小朋友们尝试自己穿鞋子，给爸爸妈妈一个惊喜。
- 幼儿表现：幼儿思考并回答教师的问题。
- 视觉/手势提示：教师展示笑脸，鼓励幼儿。
- 支持措施：教师鼓励所有幼儿，不特别指出任何幼儿。
- 观察要点：观察幼儿是否能理解并记住教师的建议。

## 六、个别化差异目标

| 层级 | 适用人数 | 目标 | 起点与评量 | 未达标的下一步 |
|---|---|---|---|---|
| A | 约 4 名 | 说出鞋子的基本组成部分，如鞋跟、鞋面、鞋带等，并能正确匹配图片和实物。 | 能够正确匹配3种以上鞋子的基本组成部分。；观察幼儿在操作图卡和实物时的匹配正确率。 | 通过提供更多不同样式的鞋子进行练习，提高幼儿的识别能力。 |
| B | 约 3 名 | 能正确区分左右鞋，并在视觉提示下独立完成穿鞋子的过程。 | 能够正确区分左右鞋，并在成人的帮助下完成穿鞋子的过程。；观察幼儿在视觉提示下独立完成穿鞋子的过程。 | 增加视觉提示的难度，如去掉提示图片，提高幼儿的独立操作能力。 |
| C | 约 5 名 | 在视觉提示和操作图卡的支持下，独立完成穿鞋子的过程。 | 在操作图卡的支持下，能够完成穿鞋子的过程。；观察幼儿在操作图卡支持下的穿鞋过程。 | 逐步减少操作图卡的使用，鼓励幼儿完全独立完成穿鞋子的过程。 |

## 七、活动延伸与家园共育

1. 生活延伸：在家庭中，鼓励幼儿尝试自己穿鞋子，并引导家长观察幼儿的进步。
2. 家园共育：与家长沟通，共同制定幼儿在家穿鞋子的计划，并定期反馈幼儿的进步。

- 请在家与孩子一起练习穿鞋子，鼓励孩子尝试独立完成。

## 八、应变的备选方案

- **当幼儿无法完成指认或命名时**：改为让幼儿用手指出、点头示意，或从两个选项中挑选一个（评量：能在两个选项中正确选出，即视为达成）
- **当幼儿无法用语言表达时**：改为提供图片选择、点头摇头、或用手指点（评量：能用非语言方式正确回应，即视为达成）
- **当幼儿情绪不稳不愿参与时**：允许先旁观，老师把他安排在同伴旁边，待情绪平稳后再邀请（评量：能在活动结束前加入并完成一次回应，即视为达成）
- **当幼儿精细动作完成困难时**：改为使用更大的材料，或由老师扶住材料、幼儿完成最后一步（评量：能在辅助下完成最后一个动作，即视为达成）

## 九、活动反思（留白供教师课后填写）

- 本次活动中，哪些幼儿需要比预设更多的支持？
- 哪个环节的提示可以再减少一些？
- 复练次数是否足够？下次是否需要增加？
