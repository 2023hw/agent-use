# 融合教育教案分层机制设计说明

> 本文回答四个问题：①为什么范例里的 `1345` 不能当"难度档位"直接用；
> ②**分层怎么定、分几层**；③**每个孩子落到哪一层**；④层级怎么随评量结果
> 动态调整、调整后「康复目标 / 康复基线」怎么变。

---

## 〇、一句话结论

`1345` 不是"第 1、3、4、5 难度档"，是"**本课我要评估第 1、3、4、5 条目标**"。
分层 = 按孩子已有的能力，**从本课阶梯里给他选几条目标**。

分几层**不预设**：数语料里「康复目标」的组合规律有多少种，就分多少层 ——
现从 13 份范例、170 条记录里数出 **4 种**，所以是 **4 层**（不是写死的 3 层）。

---

## 一、先纠正一个关键误读

最初的猜想是：

> "基于范例中的个别化差异目标判定康复目标的组合与分层（如可设为 1345 一层、
> 1456 一层、126 一层）"

**方向对（确实是用编号的组合来分层），但把 `1345` 理解成了"第 1、3、4、5
档难度"。实测数据不支持这个解释。**

### 证据 1：组合里的每个数字都能在左栏找到对应条文

以 `第四周-三月三(1).docx` 为例，左栏「个别化差异目标」是 6 条带编号的条文：

| 序号 | 条文 |
|---|---|
| 1 | 整节课堂能安坐好不走出位置不闹情绪 |
| 2 | 能在身体辅助下完成指认三月三习俗名称 |
| 3 | 能在少量手势辅助下完成指认三月三习俗名称 |
| 4 | 能自己独立完成指认三月三习俗名称 |
| 5 | 能自己看图表达三月三习俗名称 |
| 6 | 能参与抛绣球的游戏 |

右栏儿童表的 `1234` / `124` / `125` / `123` —— **每个数字都能在左栏找到条文**，
一一对应、不多余、不跳号。这是**选条**，不是"档位"。

### 证据 2：组合条数只可能是 3 或 4，不固定为 3

全部 13 份范例、170 条儿童记录：

| 集合大小 | 出现次数 | 典型集合 |
|---|---|---|
| 4 条 | 79 | `1,4,5,6`(24) / `1,2,3,4`(18) / `1,2,4,5`(16) |
| 3 条 | 91 | `1,2,3`(26) / `1,5,6`(21) / `1,4,5`(20) |

`min=3  max=4  avg=3.37`，**从来没有 2 条**。所以选条函数必须保证每层落 3~4 条。

### 证据 3：条文本身是"支持轴 + 发展轴"二维阶梯

`第二周-动物的家(1).docx`：

| 序号 | 条文 | 轴 |
|---|---|---|
| 1 | 能够在课堂上安坐不走出位置 | 课堂常规 |
| 2 | 能看图片认识动物 | 发展轴 |
| 3 | 能在**全辅助**下通过障碍物把动物送"回家" | 支持轴 |
| 4 | 能在**少量辅助**下通过障碍物把动物送"回家" | 支持轴 |
| 5 | 能**自己**通过障碍物把动物送"回家" | 支持轴 |

3/4/5 是**同一任务**，差别只在辅助量 → **支持轴**。
再看 `第四周-能干的我(1).docx`：2/3/4 是"身体辅助→少量手势辅助→独立"（支持轴），
5/6 换成了新任务（"我会擦桌子"表达 / "听令去做"）→ **发展轴**。

**结论：条文阶梯 = 支持轴 × 发展轴 二维网格；「康复目标」列 = 这名孩子本课
要评估哪几条。**

## 二、分层：层数由**组合规律**决定（现为 4 层）

### 什么是「组合规律」

把每条组合翻译成**轴位签名**：

| 记号 | 含义 |
|---|---|
| `R` | 课堂常规条（人人必选，本课为第 1 条） |
| `S1` `S2` `S3` | 支持轴第 1/2/3 档（S1 = 需支持最多） |
| `A1` `A2` | 发展轴第 1/2 条（按难度升序） |

轴位是**可跨教案移植**的 —— 各课序号都从 1 开始但内容不同，只有轴位不变。

### 4 种规律 → 4 层

13 份范例、170 条记录里的组合，**只落在 4 种轴位形态上**：

| 层 | 名称 | 组合规律 | 所需支持 | 语料里的实例 | 基线 P 密度 |
|---|---|---|---|---|---|
| L1 | 高支持层 | `R+S1+S2` | 身体辅助 | `123` / `134` | **0.48** |
| L2 | 中支持层 | `R+S1+S3` | 少量手势辅助 | `124` / `1234` / `1346` | **0.56** |
| L3 | 低支持层 | `R+S3+A1` | 独立完成 | `145` / `125` / `135` | **0.80** |
| L4 | 泛化层 | `R+S3+A1+A2` | 独立完成并泛化 | `1456` / `1345` / `156` | **0.92** |

### 分层的独立证据：基线 P 密度单调递增

`P 密度` = 该层孩子的「康复基线」里 `P` 占比。它是**独立于分层规则**的观测：

```
L1 0.48  <  L2 0.56  <  L3 0.80  <  L4 0.92
```

层越高，孩子接手本课时已达标的条目越多 —— 分层与实际能力一致。

> 复算：`python scripts/mine_layer_tiers.py` → `data/structured/layer_tiers.json`
> （只统计"四条规律互不撞车"的教案，此时组合 ↔ 规律唯一对应，归因干净）。
> 层数改由 `lpa.layering.layer_count()` 读取该 JSON，**代码里没有 3/4 的硬编码**。

### ⚠ 硬约束：每层 3~4 条、各层组合互不相同

阶梯过短时两条规律可能落到同一个组合（如只有 1 条进阶条时 `R+S3+A1` 与
`R+S3+A1+A2` 相同）。`layer_combos()` 逐层去重：撞车就往上补一条"尚未用到、
支持档最高"的条文，保证 N 层是 N 个不同组合。

## 三、定层：孩子落到哪一层

### 规则

```
层级 = 他/她「最近一次**可解释**的记录」里的组合，落在哪条规律上
        ↓ 往前逐条回退，一条都没有
      回落「能力画像判定」层
```

**可解释** 的判据（`lesson_flow.interpretable`）：
组合里的编号**全部**落在该课阶梯内，且条数 ≥ 3。

> 为什么必须"全部落在阶梯内"：各课编号含义不同 —— 本课「4」是独立档，
> 别课「4」可能是进阶条。所以**不能**把上一课的组合拿到本课阶梯上硬解释。
> 语料里有几份教案的阶梯没能从范例原文完整恢复（如《动物的家》原文缺「1.」），
> 其上记录的组合会带出越界编号，此时宁可跳过、往前回退。

### 两条来源都写清（附录表三「判定依据」列）

| 来源 | 判定依据写法 |
|---|---|
| 组合规律定层 | 「本人最近记录（2025年4月21日—4月25日）组合 156 属 R+S3+A1 规律 → L3；上一份评量 … → L4」 |
| 画像回落 | 「领域「认知」 支持层级「独立完成」→ 档 4；达标率 0.87 → 档 4；取更需支持侧 = L4」 |

**判定依据与层级必须同源** —— 早期版本依据来自画像、层级来自组合规律，
出过"依据写 L4、层级却是 L1"的自相矛盾行，已修正。

### 实测（本课产物）

```
定层来源：按组合规律 26 名 | 画像回落 11 名
```

11 名回落的成因：其中 9 名（S29–S37）全班只有一份 `闪电班4月21日主题教案`
的记录，而该课阶梯未从范例恢复；另 2 名无可用记录。附录页已注明来源。

## 四、调层：随评量结果动态调整

### 规则（用户指定的阈值）

| 触发条件 | 动作 |
|---|---|
| **连续 2 次**评量达标率 **≥ 85%** | **上调一层** |
| 单次评量达标率 **< 40%** | **下调一层** |
| 该次评量为「未参与」 | **跳过**：不计入分母、不触发调整 |
| 无数据 | 保持当前层 |
| 上限 / 下限 | **L4 / L1**（层数取自 `layer_count()`） |

### 为什么这样设计

- **上调要"连续 2 次"**：单次做得好可能是运气/状态好，连续两次才是能力稳了。
  这是特殊教育评估里的"稳定性"原则。
- **下调只要"单次 < 40%"**：上调谨慎、下调敏感。宁可让孩子在低支持层多待一次课，
  也不要让他在高支持层反复挫败 —— 挫败会直接破坏课堂参与动机。
- **「未参与」必须排除**：范例里大量出现（如某幼儿全 5 次未参与）。
  若当 0 分计入，会凭空把请假的孩子降层。这是**纠正性规则**，不是可选项。

### 实测轨迹（产物附录表四）

```
第1次 P率=1.0  hold  → L2   连续 1/2 次，再观察
第2次 P率=1.0  up    → L3   连续 2 次 ≥ 85%，上调
第3~5次        hold  → L3
```

## 五、升级后「康复目标」怎么变

换成**本课阶梯上该层的规律实例**（跨课复用规律、换课换条文）：

```
新层 L → layer_combos(本课阶梯)[L]
```

例（本课 6 条阶梯）：`L1=1/2/3`、`L2=1/2/4`、`L3=1/4/5`、`L4=1/4/5/6`。

---

## 六、升级后「康复基线」怎么变（用户指定）

**逐位对齐本课的新组合**（`lpa.layering.compose_baseline`）：

| 情形 | 记号 |
|---|---|
| 旧组合里**保留**的目标 | **沿用原记号**（原来是 P 就还是 P） |
| **新加入**的目标 | **E**（未达标 —— 该目标本课还没评估过） |
| 整轮未参与 | 统一写「未参与」，且不调层 |

### 与语料写法的偏差（如实记录）

复算语料里 63 对相邻记录：**保留目标 93% 沿用原记号**（与规则一致 ✅），
但**新增目标只有 27% 写 `E`**，48 例老师直接写了 `P`。

> 本实现按**用户指定口径**执行（新增记 `E`）。如需复现语料写法，把
> `compose_baseline(..., new_mark="P")` 即可 —— 一个参数的事。

### 另一条实测依据

《第四周-能干的我》主表里，同一阶梯：

```
朱品合  134  基线 P   PP（全 P）  评量 E  E E → EEE → PEE → PPE → PPP
甘海燕  123  基线 P  E E（1P2E）  评量 E  EE → E  EE → P  EE → P  EE → P  EE
```

**基线全 P 的孩子评量很快稳定在 PPP；基线 1P2E 的长期 E 多。**
说明基线是"起点能力"，起点高、进步快 —— 所以连续达标后下一课的起点就该提高。

### ⚠ 「未参与」不是 P/E 串

触发条件是**该幼儿整轮未参与**（五次评量全为「未参与」），不是缺某几次：

```
第三周-浓浓端午节   某幼儿   基线 未参与   五次评量 全 未参与
反例（只缺某几次，基线照常）：P  EE / P  EE / PEE
```

规则：整轮未参与 → 基线写「未参与」、**不计分母、不触发调层**；
缺勤优先于"阶梯是否可解释"判定（缺勤是事实，不因上一课阶梯没恢复好就改判）。

## 七、主表那几列的分工

| 列 | 内容 | 谁填 | 什么时候 |
|---|---|---|---|
| **个别化差异目标** | 本课目标条文总表（全班共用，带 `1.`…`6.` 编号，只写第一行） | 系统 | 课前 |
| **儿童姓名** | 代号 `S01`…`S37`（全班在册，真实姓名已匿名化） | 系统 | 课前 |
| **康复目标** | 该幼儿本课要评估的条文编号，**连写**如 `1456` | 系统 | 课前 |
| **康复基线** | 该幼儿接手本课时的能力水平，`P/E` 串如 `P  P PP` | 系统 | 课前 |
| **评量效果** | 本课 5 次实际评量结果 | 教师 | 课后 |

三条硬规律（实测 14 份范例、189 条记录，空值 0 条）：

1. **记号个数 == 本课目标条数**（可比 178 条，178/178 一致）；空格只是与编号**逐位对位**的留白。
2. **跨教案传递**：27 名出现 ≥2 次的幼儿里，12 名的基线串**一字不差**。
3. **是能力属性，不是"上一课评量"的照抄**：某幼儿在《童心向党》五格全是「未参与」，
   基线仍写作 `PEEE`，与更早的《快乐六一》一模一样。

## 八、附录页（不进正文，另起一页）

正文主表「康复目标」列**只写编号组合**（与范例一致）；层级归属另起一页附录，
含 4 张表：

| 附录表 | 内容 |
|---|---|
| 一、分层依据（目标阶梯） | 本课条文逐条编号 + 轴位标注 |
| 二、N 个层级与目标组合 | 层级 / 定义 / 所需支持 / **组合规律** / 本课目标组合 |
| 三、儿童代号与所属层级 | 代号 / 层级 / 层名 / 本课目标组合 / **判定依据**（注明来源） |
| 四、随评量结果的层级调整机制 | 代号 / 初始层级 / 第1~5次评量 / 调整轨迹 |

儿童一律用**代号**（S01…S37），**不出现姓名、不出现诊断、不出现障碍标签**。

## 九、本课产物实测

```
分层 4 层（按组合规律）：L1=12  L2=9  L3=2  L4=14
各层组合：L1=1/2/3   L2=1/2/4   L3=1/4/5   L4=1/4/5/6
调层：升级 8 | 维持 24 | 降级 2 | 未参与（不调层） 3
康复基线：保留沿用 + 新增记 E（34 条）| 未参与 3 条
定层来源：按组合规律 26 名 | 画像回落 11 名
```

校验：`python scripts/final_audit.py` → 组合 4 种合法、4 层齐全、基线记号数对齐、姓名/标签违规 0，**总判定 PASS**。

复算链路：

```
scripts/mine_layer_tiers.py   → data/structured/layer_tiers.json（4 层规律与 P 密度）
scripts/lesson_flow.py        → 自检打印各层组合与每名幼儿 L/目标/基线
scripts/run_render.py         → 产出 data/docx/认知课《国庆节到了》.docx
scripts/render_preview.py     → data/preview/*.html
scripts/final_audit.py        → 终检
```
